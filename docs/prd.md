
## Product Requirements Document (PRD)

### Product Name

**RecallBox**

### One-Line Description

RecallBox stores your notes, facts, and procedures and helps you find them later using natural language.

---

## Problem Statement

People save things everywhere:

* Notes apps
* Screenshots
* Chat apps
* Random documents

The problem is not saving.
The problem is **finding**.

“Where did I write that Wi-Fi setup?”
“What app has the server config steps?”

RecallBox exists to be **one trusted place for recall**.

---

## Core Principle

**Store simply. Retrieve naturally.**
No folders. No strict structure. Just memory that answers back.

---

## Target Users

* Developers
* Students
* Professionals
* Anyone tired of re-searching their own knowledge

---

## Core Functionality (MVP)

### 1. Save Knowledge

User can save:

* Facts
* Step-by-step procedures
* Short notes
* Copied text

Optional title. Text-first only.

---

### 2. Ask Natural Questions

User searches by asking:

* “Where did I save the Wi-Fi setup steps?”
* “Show me the note about API keys”
* “How do I reset that router?”

No keywords required.

---

### 3. Smart Retrieval

The app:

* Finds the most relevant saved item
* Highlights matching parts
* Shows original context

No hallucination. Only saved content.

---

## Example Flow

**Saved Note:**
“Office Wi-Fi Setup:

1. Connect to NetPlus
2. Password is written under the router
3. Restart if connection fails”

**User Query:**
“Where did I save the Wi-Fi setup steps?”

**Result:**
Shows the note with steps highlighted.

## Non-Goals (Important)

* Document editing suite
* Collaboration
* Cloud syncing (initially)
* External web knowledge

RecallBox remembers **your** knowledge, not the internet’s.

---

## Safety & Trust

* No fabrication
* No external data mixing
* Retrieval only from user content

Trust is the product.

---

## Success Metrics

* User finds notes faster
* Fewer duplicate notes created
